MicroViber — UI Mockup · revision 2

Mobile PWA for driving laptop Claude Code sessions. Dark theme only, three controls (session picker, composer, pane switch). Frames cover every state in docs/features/microviber/spec.md §7. Click any element to annotate it.

Changed in revision 2, from your feedback: the transcript now follows the Claude Code VS Code extension's conventions — a flowing document with left-gutter markers rather than chat bubbles, user prompts as bordered blocks, rich markdown (bold, numbered lists, inline code chips, links), and tool output in the extension's labelled OUT block. The composer now rests at 7 lines and grows to 10 instead of a single line.
